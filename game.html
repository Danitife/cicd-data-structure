From objects to a working game

Build it step by step

New to classes? Start with the OOP primer (run node oop.js to try the examples). Then expand each step in order. The listings are pulled from the actual script this game runs; the comments explain what each line does and why it is there.

00 · Give the game a place to draw

HTML defines the canvas, buttons, and scoreboard. The canvas is a blank drawing surface; CSS makes it fit the page without changing the 720 × 420 coordinate system the game uses. tabindex="0" lets keyboard players focus the playfield. Coordinates start at the top-left: x increases to the right and y increases down.

<canvas id="field" width="720" height="420" tabindex="0">
  This game needs a browser with Canvas support.
</canvas>
01 · Connect JavaScript to the page

Find the HTML elements by ID and ask the canvas for a 2D drawing context. The game reuses these references rather than searching the page every frame.

02 · Define a shared Sprite class

Every game object has a position and size. Put that shared state and rectangle-overlap rule in one class. In this.x, this is whichever object the method was called on.

03 · Create a Ship, a Pulse, and a Target

Each is a kind of sprite, so they inherit position, size, and collision logic. Each defines its own draw(). Calling the same method on different objects and getting different behavior is polymorphism.

04 · Compose the objects into a Game

A game has a ship, pulses, and targets; it isn't a kind of sprite. The game coordinates those objects, while private methods keep its rules out of the page's button handlers. A frame is one update followed by one drawing pass.

05 · Hook up keyboard, touch, and demo mode

Event listeners record what you're holding. The game loop reads that state to determine movement and firing. In demo mode, the game supplies those inputs itself.

06 · Try changing the rules

Change MAX_LIVES from 3 to 5, or set this.speed in Ship to 240. Save and reload the page. Which change belongs to the game, and which belongs to the ship?
